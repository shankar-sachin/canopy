Pull requests, issues & CI.

Canopy talks to GitHub through the official GitHub CLI, gh. Your login, your permissions, nothing new to trust.

Setup

GitHub features need gh, logged in. Canopy never installs anything itself; if gh is missing or logged out, the GitHub tabs show exactly what to run.

$ brew install gh
$ gh auth login

That's it. Open Canopy in any repository whose remote is on github.com.

0 · Actions

Workflow runs for your branch (f for all branches), refreshing every few seconds while any run is in progress. Select a failed run to see which job and step failed, and the end of its log, cleaned up so you can read it. R re-runs the failed jobs.

On Home

Home's GitHub card shows your branch's pull request, whether its checks pass, and how many reviews are waiting for you. Next steps picks it up too: failing checks, requested changes, or a green, approved PR ready to merge.

What Canopy sends

Nothing of its own. Every GitHub action is a gh command run on your machine with your login. Teach mode shows each one, for example gh pr merge 12 --squash --delete-branch. GitHub is only contacted when you open a GitHub tab, refresh, or act, never in the background while you work on other tabs.
