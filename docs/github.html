GitHub

Pull requests, issues & CI.

Canopy talks to GitHub through the official GitHub CLI, gh. Your login, your permissions, nothing new to trust.

On this pageSetupPull requestsLine commentsIssuesNotificationsActionsCI logsReleasesOn HomeWhat Canopy sends

Setup

GitHub features need gh, logged in. Canopy never installs anything itself; if gh is missing or logged out, the GitHub tabs show exactly what to run.

$ brew install gh
$ gh auth login

That's it. Open Canopy in any repository whose remote is on github.com.

8 · Pull requests

Open pull requests with their checks (✓ 2/2, ✗ 1 failed), review state, author, and age. f cycles between open, yours, review requested, and all. The side panel shows the description, every check, reviews, and comments; D adds the diff, with review comments shown under the lines they're about.

Comment on a line

Press D to show the diff, ↵ to move into it, and put the cursor on the line you mean. Press C, write the comment, and press ⌃S. It shows up on GitHub as a review comment on that line. Comments on removed lines go on the old side of the diff. Existing comments appear right under their lines, with the author and when they wrote it.

9 · Issues

Open, assigned-to-you, or all issues, with labels and comment counts. Read the full discussion in the side panel, then n to file one, C to comment, X to close (or reopen a closed one).

Notifications

Press ] on Issues to switch to your GitHub inbox: review requests, mentions, assignments and CI results, newest first, with unread ones marked ●. f switches between this repository and everywhere, and u between unread and all.

0 · Actions

Workflow runs for your branch (f for all branches), refreshing every few seconds while any run is in progress. Select a failed run to see which job and step failed, and the end of its log, cleaned up so you can read it. R re-runs the failed jobs.

Read the whole log

Press L on a finished run to open its full log. Failed jobs come first and the viewer starts on the first error. Timestamps, color codes and runner noise are stripped.

/Search (ignores case; matches are highlighted)
n / NNext / previous match
j k, ⌃D ⌃UScroll a line, or a page
g / GTop / end
escClose

Releases

Press ] on Actions to see releases: tag, title, date, and whether each is a draft, pre-release or the latest. The side panel shows the notes and the files attached. n creates a release. Canopy suggests the next tag (after v1.2.0 comes v1.2.1), and if you leave the notes empty, GitHub writes them from the merged pull requests.

On Home

Home's GitHub card shows your branch's pull request, whether its checks pass, and how many reviews are waiting for you. Next steps picks it up too: failing checks, requested changes, or a green, approved PR ready to merge.

What Canopy sends

Nothing of its own. Every GitHub action is a gh command run on your machine with your login. Teach mode shows each one, for example gh pr merge 12 --squash --delete-branch. GitHub is only contacted when you open a GitHub tab, refresh, or act, never in the background while you work on other tabs.
