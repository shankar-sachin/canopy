Every key.

Generated from Canopy's own key tables, so it always matches the app. Screen keys take priority over the global ones. Remap anything with the [keys] table in your config, using the names in the last column.

On this pageEverywhereChangesDiff panelConflict panelHistoryBranchesTagsRemotesWorktreesSubmodulesStashWorkspaceReflogPull requestsIssuesActions
Keys are shown the Mac way: ⌃ is Control, ⌥ is Option (Alt on other keyboards), ⇧ is Shift. Option shortcuts work in any terminal, including macOS Terminal's default setup where Option types special characters. ⌃Q and ⌥Q quit from anywhere, even inside a dialog. In Canopy itself, Linux shows ctrl-q / alt-q instead; set mac_key_symbols in the config to choose.
