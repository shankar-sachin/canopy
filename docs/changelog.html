v1.0.10 Latest

September 2026

Notifications, one step away in both apps.

  • Desktop app: a Notifications page in the sidebar, with a count of unread ones there and on Home. It shows every repository or just this one, unread or all, and says why you got each. Open one in Canopy (pull requests and issues in this repository), view it on GitHub, mark it read, or mark all read.
  • Terminal app: ⌥N opens your notifications from any tab, and the header and Home show how many are unread. ] on Issues still works.

v1.0.9

September 2026

Getting the Mac app ready for notarization, and a quieter terminal app.

  • Desktop app (macOS): Canopy now declares that it opens Terminal (the Apple Events permission Apple requires), and macOS asks for it early, the first time Canopy starts while Terminal is open, instead of in the middle of Fix with AI.
  • If macOS blocks Canopy from opening Terminal or iTerm, Fix with AI and terminal editors now say so and point to the setting that allows it, instead of claiming a window opened.
  • The terminal app no longer suggests the desktop app: the startup tip, ⌥D and the desktop_tip setting are gone.
  • Desktop app: now and then (at most every two weeks) it mentions Canopy for the terminal, if you don't have it. Turn it off in Settings → General.
  • Terminal app: started without a terminal (by a script or an installer's check), canopy prints what it is and exits instead of failing. Windows builds include the C runtime, so canopy.exe runs on a clean machine.

v1.0.8

September 2026

One Canopy, two ways to use it. Canopy Desktop is where to start. Canopy for the terminal does everything, from the keyboard. Nothing is renamed: the canopy command, Homebrew and winget packages stay the same.

  • Desktop app: every term explained. Hover over (or click ? on) Staged, Changed, Conflicts, Stashes, Branches and Remotes on Home, and over the ↑/↓ counts, to see what they mean.
  • Desktop app: a short New to git? card on Home (change, stage, commit, push) with links to the wiki. Dismiss it; Settings → General brings it back.
  • Desktop app: a button on every next step. Connect to GitHub… when a repository has no remote (create it on GitHub, or connect an existing one over HTTPS or SSH), and Open History during a bisect.
  • Desktop app: after a commit, checkout, merge, cherry-pick, revert or reset, the message reminds you that ⌘Z undoes it.
  • Desktop app: Settings → General shows whether the terminal app is installed, and the command to install it.
  • The website leads with the desktop app. The terminal app's tour is now Canopy for the terminal, and Get started has a path for each app.

v1.0.7

September 2026

Your own themes, shared between the terminal and desktop apps.

  • Themes are JSON files in ~/.canopy/themes/. The terminal app picks them up for theme, -t and ⌃T; canopy --list-themes lists them and canopy --export-theme nord gives you one to start from.
  • Desktop app: Settings has a new Appearance page with every theme (catppuccin, gruvbox and nord are new there) and a theme editor: pick colors and see them live, with a preview of the terminal app. Save it and the terminal app can use it straight away. Themes can be imported, exported, or opened in your editor as JSON.
  • Move settings between the apps: the theme, text editor, AI assistant and the show-commands setting. canopy --export-settings / --import-settings FILE in the terminal; Import from terminal app, Send to terminal app, Export and Import in the desktop app.
  • Choose your text editor: editor = "code --wait" in the terminal app's config; in the desktop app, Settings lists the editors it finds (VS Code, Cursor, Zed, Sublime Text, Neovim, Vim, Helix, nano, Emacs) or takes any command. Terminal editors open in a new terminal window.
  • Desktop app: Open in editor on the Changes page (and on conflicted files); Details on a failed run opens in your chosen editor.
  • Canopy's folder is now ~/.canopy (CANOPY_HOME to change it). Your settings from ~/.config/canopy are copied over the first time 1.0.7 runs.

v1.0.5

September 2026

Fix with AI: when CI fails, hand it to Claude Code or Codex.

  • Canopy writes a prompt from the failure (the failed job and step, GitHub's summary, including why a workflow file is invalid, and the cleaned-up log) into .git/canopy/fix-ci.md, then opens your assistant in a new terminal tab or window, already working on it.
  • Terminal app: A on a failed run in Actions. Home's next steps point to it when checks fail. Configure with ai and ai_open.
  • Desktop app: a banner on Home when your latest commit fails, and Fix with … on failed runs; choose the assistant in Settings.
  • Works with Claude Code, Codex (whichever is installed) or any command you set.

v1.0.4

September 2026

Start a new repository, in the terminal and the desktop app.

  • Open a folder that isn't a repository and Canopy offers to create one instead of stopping: pick a branch name, a .gitignore for your language, a README and an MIT license, and make the first commit.
  • Then connect it to GitHub: create it there with the GitHub CLI (private or public), or connect an existing repository by owner/name or URL.
  • HTTPS or SSH, explained where you choose, with a suggestion based on your GitHub CLI setting and whether you have an SSH key. The desktop app previews the address as you type.
  • The desktop app's welcome screen has Start a new one….
  • Menus in the terminal app wrap long descriptions instead of cutting them off.

v1.0.3

September 2026
  • Canopy Desktop on Windows 11 (x64 and Arm): winget install shankars.canopy-desktop, or the installer from the release. A release preview, not code-signed yet.
  • Homebrew installs a prebuilt binary, so brew install shankar-sachin/canopy/canopy works on Linux without a C compiler, and it's faster on a Mac.

v1.0.2

September 2026

Canopy Desktop: the dashboard as an app for macOS and Linux, as a release preview.

Canopy Desktop (preview)

  • Home with next steps you can click, and this branch's pull request.
  • Changes: stage files, hunks or single lines with a click; discard; resolve conflicts; commit and amend.
  • History with a real commit graph, search, and every commit's diff; Branches, tags, remotes and Stash; Undo.
  • GitHub: pull requests (review, merge, check out), issues, and Actions runs with the failed log.
  • Fetch, pull and push with live progress; settings; update checks that know if you installed with Homebrew.
  • Install: brew install --cask shankar-sachin/canopy/canopy-desktop, or a .dmg, .deb or AppImage from the release. Not notarized by Apple yet, so macOS asks you to confirm the first time.

Terminal app

  • Now and then Canopy mentions the desktop app at startup; ⌥D shows how to get it. desktop_tip = false turns the tip off.
  • Fixed: History with all branches no longer shows the internal commits of stashes.

Windows becomes a fully supported platform.

  • Windows on Arm: a native Arm64 build with every release; the install script picks it automatically.

v1.0.0

September 2026

Canopy is feature-complete: everything you do with git and gh day to day, in one dashboard.

More GitHub

  • Inline review comments: the PR diff (D) shows review comments under their lines, and C on a line of the diff comments right there.
  • CI log viewer: L on a finished run opens its whole log, failed jobs first, starting on the first error. / searches and n/N jump between matches.
  • Notifications (] on Issues): your GitHub inbox for this repo or everywhere. Mark one or all read.
  • Releases (] on Actions): notes and downloads. n creates a release with the next tag suggested and notes written by GitHub.

Everywhere

  • Windows: a prebuilt canopy.exe with every release (see Get started). macOS and Linux stay the main platforms.
  • The title row, logo and teach line are spaced out vertically, so the layout reads more cleanly.
  • A new wiki recipe: Fix a failing CI run.

v0.4.0

September 2026

The Canopy wiki

  • The wiki: beginner guides, step-by-step recipes (undo, conflicts, tidy history, find a bug, review a PR…), and a full reference.
  • The website gets one top bar with dropdown menus, site-wide search (⌘ K / Ctrl K), and light and dark themes.

Look and feel

  • The Canopy logo: a vector mark for the web, and a block-art tree inside the terminal.
  • A startup animation: the tree grows while your repo loads (any key skips it; splash = false turns it off).
  • More breathing room: padding, gaps between panels, a side gutter, and the logo in the top-right corner. compact = true brings back the dense layout.
  • The key hints always keep ? help visible, and detail panels wrap to fit.

v0.3.0

September 2026

GitHub

  • Pull requests tab (8): checks, reviews, diff; check out, create, review, comment, merge, close.

Polish

  • Borders line up in every terminal: Canopy only draws glyphs that are one column wide everywhere.
  • The tab bar shortens itself on narrow terminals.
