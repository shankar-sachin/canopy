v0.3.0 Latest

September 2026

GitHub

  • Pull requests tab (8): checks, reviews, diff; check out, create, review, comment, merge, close.
  • Issues tab (9): browse, file, comment, close and reopen.
  • Actions tab (0): live run status, failing steps and log tail, re-run failed jobs.
  • Home shows your branch's PR, its checks, and reviews waiting for you.

Git

  • File history (L) that follows renames, and blame (B).
  • Guided bisect (b).
  • Worktrees and submodules views in the Branches tab.

Polish

  • Ctrl and Option shortcuts: ctrl-q/option-q quit from anywhere, option-1…option-0 jump to tabs, option-←/→ cycle them, plus Option versions of commit, pull, push, fetch, stash and undo.
  • Borders line up in every terminal: Canopy only draws glyphs that are one column wide everywhere.
  • The tab bar shortens itself on narrow terminals.

v0.2.0

September 2026
  • History loads more commits as you scroll.
  • Remap any key with [keys] in the config.
  • Tags and remotes views in the Branches tab.
  • Resolve merge conflicts one at a time: ours, theirs, or both.

v0.1.0

September 2026
  • The first release: Home, Changes with line-level staging, History with a commit graph and interactive rebase, Branches, Stash, Workspace, Reflog.
  • Undo with z, teach mode, command palette, five themes, custom commands.

What's next

  • v0.4: the Canopy wiki, with guides, recipes, and a full reference.
  • Later: syntax-highlighted diffs, and a desktop GUI.
