2 · Changes

Everything you've changed, grouped as conflicts, changes, and staged. space stages or unstages a file, a does all of them, d discards (after telling you exactly what you'll lose).

Press ↵ to step into the diff. There, space stages just the line under the cursor, v selects a range, and ↵ takes the whole hunk. s switches to a side-by-side view.

3 · History

The commit graph for your branch, with branch and tag labels. / filters by message, author or hash. On any commit: check it out, cherry-pick C, revert t, reset r (soft, mixed or hard), tag T, branch from it n, or fold staged changes into it F.

Conflicts

When a merge or rebase stops on conflicts, the header says so and Home tells you what to do. Open a conflicted file with ↵ and resolve it one conflict at a time: o keeps yours, t takes theirs, b keeps both. The file is written as you go and staged when nothing's left; u puts the markers back if you change your mind. Then C continues the merge or rebase.

4 · Branches, tags, remotes, worktrees & submodules

One tab, five views: [ and ] switch between them.

  • Branches: local and remote, with ahead/behind. Checkout, create, rename, delete, merge M, rebase r, set upstream.
  • Tags: create (name: message makes an annotated tag), push, delete here or everywhere.
  • Remotes: add, rename, change URL, fetch one, remove.
  • Worktrees: check out another branch in its own folder, open it in Canopy, remove or prune.
  • Submodules: see which are in sync, update one or all, open one.

5 · Stash and 7 · Reflog

Stash shelves your uncommitted work (S from anywhere) so you can switch tasks; apply, pop or drop it later. Reflog lists everywhere HEAD has been, including commits you "lost" to a reset. Reset back to any entry from there.

Undo

z undoes the last thing that moved your branch, using git's reflog. Canopy tells you what it's about to do first:

  • After a commit: the commit is undone and its changes come back staged.
  • After a checkout: you switch back to where you were.
  • After a reset, merge or rebase: the branch moves back, and your uncommitted changes are kept.

Bisect

Something broke, but you don't know when. In History, select a commit where it still worked and press b. Git checks out a commit halfway between; test it, press b, and answer good or bad. The header counts down the steps left, and when git finds the culprit, Canopy selects it in History.

Command palette & teach mode

: or ⌃P opens the palette: type a few letters of any action and press ↵. ! runs any git command you like. With teach mode on (T toggles it), the footer shows the exact git command behind each action you take.
