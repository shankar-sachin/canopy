Real frames rendered by Canopy itself, not mockups.

Everything git does

One screen for the whole repository.

What changed, what's staged, where your branch stands, and what to do next. Every action is one key away, and every key is discoverable.

Stage single lines

Open any diff, then stage or unstage a line, a range, or a hunk. Craft commits that say exactly one thing.

Undo anything

Press z to undo the last commit, reset, merge, or checkout. An undone commit comes back as staged changes.

Conflicts, one at a time

See ours and theirs for each conflict. Keep one, the other, or both. The file is staged once nothing's left.

History that makes sense

A commit graph with search, file history that follows renames, blame, and a visual interactive rebase.

Bisect, guided

Mark a commit that worked, answer good or bad at each step, and Canopy points at the commit that broke things.

Every repo, one view

The Workspace tab shows every repository in your code folders: branch, changes, and sync state.

GitHub built in

Pull requests, reviews, issues, and CI runs, through the official GitHub CLI and your own login.

Yours to configure

Five themes, remappable keys, and custom commands on any key. The palette finds every action by name.
For everyone

New to git? Fluent in git? Both welcome.

Canopy explains itself while you use it, and gets out of the way once you don't need it to.

If you're learning

  • Next steps on Home tell you, in plain words, what state you're in and which key moves you forward.
  • Teach mode shows the real git command behind every action.
  • Confirmations say exactly what a destructive action will throw away.
  • A safety net: undo with z, and a reflog view of everywhere you've been.

If you live in the terminal

  • Line-level staging, interactive rebase, fixups, cherry-picks, and bisect.
  • Vim-style keys you can remap, plus custom commands on any key.
  • Real git underneath: your hooks, config, signing, and credential helpers all just work.
  • A single ~4 MB binary that starts instantly and never blocks while git runs.
# you press space on a line in a diff, and the footer shows:
$ git apply --cached --unidiff-zero --whitespace=nowarn - # stdin: a patch with just the selected lines
# you press z after a commit:
$ git reset --soft 1f3a9c2 ← what that just ran
