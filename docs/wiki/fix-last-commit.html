Wiki/Recipes

Fix your last commit

A typo in the message, a forgotten file, or a fix that belongs in an older commit.

Change the last commit's message#

  1. On Changes (2), press A (amend). The dialog opens with the current message.
  2. Edit it and press ↵.

Add a forgotten file#

  1. On Changes (2), stage the file with space.
  2. Press A, keep the message, press ↵. The file is now part of the last commit.

Fold a fix into an older commit#

  1. Stage the fix.
  2. On History (3), select the commit it belongs to and press F. Canopy makes a fixup! commit.
  3. To squash it in, press i on the commit before it and start the rebase; see Tidy up commits.
Already pushed? Amending rewrites the commit, so the next push needs force. Canopy offers "force push (with lease)", which refuses if someone else pushed in the meantime. Only do this on branches nobody else is using.
