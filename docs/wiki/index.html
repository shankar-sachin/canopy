The canopy wiki

Learn git with canopy: one guide for canopy desktop, one for canopy console, and the ideas both share.

canopy is a friendlier way to use git. It comes as two apps that work on the same repositories and share the same settings and themes: canopy desktop, a window you click around in, and canopy console, a keyboard-driven program that runs in your terminal. This wiki has a full guide for each, plus the ideas they share.

New to git? Read Git in ten minutes first. It takes a few minutes, and everything else makes more sense afterwards. Then pick your app below.

Which app is for me?#

canopy desktop is the one to start with. It runs on macOS, Windows and Linux, shows what git is doing in plain words, and asks before anything risky. Everything is a click or a shortcut away, and it can show you the git command behind each action so you learn as you go. Its guide starts with the canopy desktop guide.

canopy console is the power tool. It lives in your terminal, works over SSH, and is built for speed: one key per action, and screens for things canopy desktop leaves out, such as interactive rebase, bisect, worktrees, the reflog and issues. If you already live in a terminal, start with the canopy console guide.

You don't have to choose. Both open the same repository, so you can commit in one and push in the other, and switching between them costs nothing.

How the wiki is organised#

Each guide has the same shape, so what you learn in one carries over to the other:

  • Start here: a tour of every page or screen.
  • Guides: the daily loop, commits, branches, syncing with a remote, and working with GitHub.
  • Recipes: short, step-by-step fixes for everyday jams, such as undoing a mistake or resolving a conflict.
  • Reference: shortcuts, settings, troubleshooting and the FAQ.

Two pages are shared by both apps: Git in ten minutes, which explains the ideas behind git, and Themes, which covers the built-in themes and making your own. The guides are listed below. Every page has the wiki's sidebar on the left, and the search box at the top of the site finds any page.
