Wiki/canopy console/Reference

Command line

The canopy command's flags, arguments and environment variables.

You start canopy console by typing canopy in a terminal. Most of the time that's all you need: run it inside a repository and it opens that repository. The options below help when you want a different folder, theme or setup.

Usage#

$ canopy [OPTIONS] [PATH]
PATHThe repository to open. Defaults to the current folder. If the folder isn't a repository yet, canopy offers to create one.
-w, --workspace DIRStart on the Workspace tab, scanning DIR for repositories.
-t, --theme THEMEUse a theme for this run only: canopy, catppuccin, gruvbox, nord, light, or one of yours.
-V, --versionPrint the version.
-h, --helpPrint help.

Options that print something and exit#

These don't open the app. They print to the terminal, so you can save the output to a file with >.

--list-themesList the built-in themes and your own, then exit.
--export-theme THEMEPrint a theme as JSON, to start your own from.
--export-settingsPrint the settings canopy desktop shares (theme, editor, AI assistant, teach mode) as JSON.
--import-settings FILEApply a settings file from --export-settings or canopy desktop to your config, then exit. Only those settings change.
--config-pathPrint where canopy reads its config.
--example-configPrint a starter config. See configuration.

Examples#

$ canopy ~/code/my-project        # open a repository from anywhere
$ canopy -w ~/code                 # pick from every repository under ~/code
$ canopy -t nord                  # try a theme for this run
$ canopy --example-config > ~/.canopy/config.toml
Careful with that last one. It overwrites an existing config file. Run canopy --config-path first to see where the file is, and only use it when you don't have one yet.

Environment variables#

CANOPY_CONFIGRead the config from this file instead of the default location.
CANOPY_HOMEUse this folder instead of ~/.canopy for the config, your themes and canopy desktop's shared settings.
CANOPY_GHPath to the GitHub CLI. Same as gh_program in the config, which wins if both are set.
VISUAL, EDITORThe editor e opens files in, for example code --wait, when editor isn't set in the config. Without either, canopy uses vi (Notepad on Windows).

If something goes wrong#

  • Nothing opens, and canopy just prints a line about itself. canopy only draws its screens when it's running in a real terminal. Started from a script or a pipe, it prints its version and how to run it, then exits. Run canopy directly in a terminal window.
  • "git was not found on your PATH". canopy runs the real git, so install it and open a new terminal. See troubleshooting.
  • "is not a folder". The PATH you gave doesn't exist, or is a file. Check the spelling.
  • "No theme called ...; using canopy". The name in -t or your config doesn't match a theme. canopy --list-themes shows every name canopy found. A theme file with a mistake in it is skipped.
