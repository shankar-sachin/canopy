Keyboard shortcuts

Every key in canopy console, by screen, generated from the app.

Every key canopy console understands, one table per screen. The tables are generated from canopy's own key tables, so they always match the app. Keys on a screen take priority over the "Everywhere" keys. Press ? in the app for help, and : to open the command palette.

The last column is the action's name. Use it to remap a key in the [keys] table of your config: see remapping keys.

Keys are shown the Mac way: ⌃ is Control, ⌥ is Option (Alt on other keyboards), ⇧ is Shift. Option shortcuts work in any terminal, including macOS Terminal's default setup where Option types special characters. ⌃Q and ⌥Q quit from anywhere, even inside a dialog. In canopy itself, Linux shows ctrl-q / alt-q instead; set mac_key_symbols in the config to choose.
