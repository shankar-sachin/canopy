Resolve a merge conflict

When a merge, rebase or cherry-pick stops because both sides changed the same lines.

You'll know you have a conflict because the header shows MERGE IN PROGRESS (or REBASE or CHERRY-PICK) and Home says how many files are conflicted.

  1. Go to Changes (2). Conflicted files are listed first, under Conflicts.
  2. Select one and press ↵. The panel shows each conflict with ours (your side) and theirs (the side you're bringing in).
  3. For each conflict, press o to keep yours, t to take theirs, or b to keep both. j/k move between conflicts. Canopy writes the file as you go.
  4. When a file has no conflicts left, Canopy stages it for you.
  5. When all files are resolved, press C to continue the merge or rebase.
