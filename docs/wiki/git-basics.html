Git in ten minutes

The handful of ideas that make git make sense, and where to see each one in Canopy.

A repository is a project with a memory#

A repository (repo) is a folder whose history git tracks. Everything git knows lives in a hidden .git folder inside it. Run canopy in any repo and the Home tab (1) shows where things stand.

Your changes live in three places#

  • The working tree is the files you edit. Changes here are listed under Changes on the Changes tab (2).
  • The staging area (also called the index) is where you gather what goes into the next commit. Staged files appear under Staged.
  • History is the commits themselves, on the History tab (3).

Staging is what lets you commit part of your work. In Canopy you can stage a whole file with space, or step into its diff with ↵ and stage single lines.

A commit is a saved snapshot#

A commit records the staged changes with a message saying why. Each commit points to the one before it, which is how history forms a chain. Press c, write a short summary (Canopy counts to 50 characters for you), and press ↵.

Good messages say why: "Fix crash when the repo has no commits" beats "update main.rs".

A branch is a line of work#

A branch is a movable name for a commit. When you commit, your current branch moves forward. Branches let you try something without disturbing main. The Branches tab (4) lists them; n makes a new one and space switches to it. HEAD means "where you are now"; History shows it as HEAD → main.

A remote is the same repo somewhere else#

A remote (usually called origin) is a copy of the repo on a server such as GitHub. Push (P) sends your commits there; pull (p) brings others' commits to you; fetch (f) checks what's new without changing your files. The header shows ↑2 ↓1 when you're 2 commits ahead and 1 behind.

You can almost always undo#

Git rarely forgets anything. z undoes your last commit, reset, merge or checkout, and the Reflog tab (7) lists everywhere you've been so you can go back further. See Undo a mistake.

Learn as you go: keep teach mode on (it is by default). The footer shows the git command behind every action you take, so the ideas on this page turn into commands you'll recognize.
