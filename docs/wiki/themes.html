Themes

The built-in themes, how to switch in each app, and how to make your own.

canopy desktop and canopy console share their themes: the same built-in five, and the same folder for your own. Pick one in either app, or make one and use it in both.

Switching theme#

In canopy desktop#

Open Settings (the gear at the bottom of the sidebar, ⌘, or Ctrl+, on Windows and Linux), choose Appearance, and click a theme's card. Auto follows your computer's light or dark setting. The change applies at once and is saved.

In canopy console#

Press ⌃T to cycle through the themes (built-in and your own). To make one stick, set theme = "nord" in config.toml, or start with canopy --theme nord for a single run. canopy --list-themes lists everything canopy found.

Five come with canopy: canopy (dark), catppuccin, gruvbox, nord and light. The samples below use the colors canopy console draws with; canopy desktop uses the same colors.

Your own themes#

A theme is a small JSON file in ~/.canopy/themes/ (on Windows, %USERPROFILE%\.canopy\themes). Both apps read that folder, so a theme made in one shows up in the other.

Start from a built-in one:

mkdir -p ~/.canopy/themes
canopy --export-theme nord > ~/.canopy/themes/ocean.json

Then change its name and any colors you like. Colors you leave out come from base:

{
  "name": "Ocean",
  "base": "nord",
  "colors": {
    "bg": "#0f1b2a",
    "accent": "#4fc1e9",
    "selection_bg": "#1d3350"
  }
}

Use it with theme = "Ocean" in the config or canopy -t Ocean; ⌃T cycles through your themes too. A file with a mistake in it is skipped with a note.

ColorUsed for
bg, fg, mutedBackground, text, and quieter text (times, hints)
border, border_focusPanel borders, and the focused panel's border
accent, accent_altTitles and highlights, and a second highlight
selection_bgThe selected row
added, removed, modified, conflictFile states and diff lines
added_bg, removed_bgBehind added and removed diff lines
hash, branch, remote, tagCommit ids, branches, remotes, tags
warn, errorWarnings and errors

With the theme editor in canopy desktop#

In Settings → Appearance, Customize… opens an editor: a name, and a color picker plus hex box for each color. The app changes as you pick, and Save theme stores only the colors that differ from the theme you started from. Themes you made appear under Your themes, with Edit…, Edit JSON, Export…, Import… and Delete. Saved themes go in the same folder, so canopy console can use them straight away. See the desktop Settings page.

Moving settings between the apps#

canopy console is set up in config.toml; canopy desktop has its own Settings page. They can swap the settings they share (theme, text editor, AI assistant, showing git commands) as one JSON file:

canopy --export-settings > my-canopy.json   # theme, editor, ai, teach_mode
canopy --import-settings my-canopy.json     # updates config.toml (and saves the theme)

In canopy desktop, Settings → General has Import from canopy console and Send to canopy console, which do the same through config.toml directly, and Export… / Import… for the file. Importing only changes those keys; your comments and the rest of the config stay as they are.

canopy console uses 24-bit color. If colors look wrong, your terminal may not support it; see its troubleshooting page.
