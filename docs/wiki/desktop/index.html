The canopy desktop guide

Everything in canopy desktop, page by page: guides for the daily loop, recipes for everyday fixes, and reference for shortcuts and settings.

canopy desktop is the friendly way to use git: a window with your repository's state on Home, a page for changes, history, branches and stashes, and pages for GitHub pull requests, issues, CI runs and notifications. This guide is for anyone using it, and needs no git background; where a word is new, the page explains it.

If you have never used git, read Git in ten minutes first, then the tour. If you already know git, skim the tour and go straight to the recipes.

How this guide is organised#

Start here walks through every page of the app. The Guides explain the everyday jobs (the daily loop, commits, branches, syncing and GitHub). The Recipes each fix one specific problem, from a typo in a commit message to a failing CI run. Reference lists shortcuts and settings, and answers common questions. Each guide and recipe shows the buttons to click, then the plain git commands canopy runs for you, so you learn git as you use it.

Prefer the keyboard and a terminal? The canopy console guide covers the same jobs there.
