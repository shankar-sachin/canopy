Get started

Up and running in a minute.

Canopy runs on macOS, Linux and Windows. It needs git; GitHub features also use the GitHub CLI.

On this pageHomebrewInstall scriptWith CargoFrom sourceWindowsFirst runConfigurationThemesUpdating

Install with Homebrew

The easiest way on a Mac:

$ brew install shankar-sachin/canopy/canopy

Then run canopy inside any git repository.

Install without Homebrew

On macOS or Linux (x86_64), this script downloads the latest release, checks its SHA-256, and puts canopy in ~/.local/bin. It doesn't need sudo. Read it first if you like: scripts/install.sh.

$ curl -fsSL https://raw.githubusercontent.com/shankar-sachin/canopy/main/scripts/install.sh | sh

A specific version: … | sh -s -- v1.0.0. Somewhere else: CANOPY_INSTALL_DIR=~/bin. To remove it: … | sh -s -- --uninstall (your config stays).

Install with Cargo

If you have Rust installed (rustup.rs), Cargo can build and install Canopy straight from GitHub. It lands in ~/.cargo/bin, which rustup already put on your PATH:

$ cargo install --locked --git https://github.com/shankar-sachin/canopy canopy-git-tui
Why canopy-git-tui? That's the package name (the name canopy was already taken on crates.io). The command it installs is still canopy.

Run from a clone of the source

To try the latest code, or hack on it:

$ git clone https://github.com/shankar-sachin/canopy.git
$ cd canopy
# run it without installing (the -- passes arguments to canopy)
$ cargo run --release -- ~/code/your-repo
# or install your local build as `canopy`
$ cargo install --locked --path crates/canopy

cargo run builds and starts Canopy in one step; the first build takes a minute or two, later ones are quick. Without a path after --, Canopy opens the repository you're in. Since you're in the Canopy clone itself, that's a handy way to try it on a real history.

Running the tests: cargo test --workspace.

Windows

Canopy runs in Windows Terminal (recommended) and in PowerShell. Homebrew is for macOS and Linux, so on Windows install it one of these ways.

With winget

winget installs Canopy (x64 or Arm), puts canopy on your PATH, and installs git too if you don't have it:

PS> winget install ShankarS.Canopy

Update later with winget upgrade ShankarS.Canopy. For the GitHub tabs, also install and log in to the GitHub CLI:

PS> winget install --id GitHub.cli -e
PS> gh auth login

Open a new terminal, then run canopy inside any repository. If winget doesn't find the package yet (new versions take a few days to be approved), use the install script below.

1. Or: install git (and optionally the GitHub CLI)

PS> winget install --id Git.Git -e
PS> winget install --id GitHub.cli -e    # only for the GitHub tabs
PS> gh auth login

2. Install Canopy

The install script downloads the latest release, checks it, installs it to %LOCALAPPDATA%\Programs\canopy, and adds that folder to your PATH. It doesn't need admin rights (read it):

PS> irm https://raw.githubusercontent.com/shankar-sachin/canopy/main/scripts/install.ps1 | iex

Open a new terminal, then run canopy. Or do it by hand:

2a. Download Canopy

Every release includes canopy-<version>-x86_64-pc-windows-msvc.zip, and from 1.0.1 canopy-<version>-aarch64-pc-windows-msvc.zip for Windows on Arm. Unzip it and put canopy.exe somewhere on your PATH, for example:

# in PowerShell, from the folder you unzipped
PS> New-Item -ItemType Directory -Force "$env:USERPROFILE\bin" | Out-Null
PS> Copy-Item .\canopy.exe "$env:USERPROFILE\bin\"
PS> [Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:USERPROFILE\bin", "User")

Open a new terminal window so the new PATH takes effect, then run canopy inside any repository.

2b. Or build it with Cargo

PS> winget install --id Rustlang.Rustup -e
PS> cargo install --locked --git https://github.com/shankar-sachin/canopy canopy-git-tui
On Windows: the config file is %USERPROFILE%\.config\canopy\config.toml. "alt" shortcuts use the Alt key. Custom commands run with cmd /C, e opens files in the editor set in VISUAL or EDITOR (for example code --wait), and teach mode shows commands quoted for PowerShell.

First run

The first time, Canopy shows a short welcome with the keys that matter and writes a starter config. From then on:

  • 1–0 switch tabs; the footer always lists the keys that work right now.
  • ? shows every key for the current screen; : searches every action by name.
  • q quits. ⌃Q, ⌥Q and ⌃C quit from anywhere, even with a dialog open.

Configuration

The config file lives at ~/.config/canopy/config.toml (canopy --config-path prints it; canopy --example-config prints a template).

theme = "canopy"            # canopy | catppuccin | gruvbox | nord | light
teach_mode = true           # show the git command behind each action
confirm_destructive = true
compact = false             # true: tighter layout, no gaps between panels
splash = true               # the tree animation when Canopy starts
workspace_dirs = ["~/code"] # folders the Workspace tab scans

[keys]                      # remap any action (names are on the Keys page)
toggle_stage = "s"
commit = ["c", "ctrl-s"]

[[custom_commands]]
key = "X"
cmd = "git push --force-with-lease"
description = "force push (safely)"
confirm = true

Themes

Five built in: canopy (forest greens), catppuccin, gruvbox, nord, and light. Set one in the config, pass -t nord, or cycle live with ⌃T.

Updating

$ brew upgrade canopy                      # Homebrew
$ curl -fsSL https://raw.githubusercontent.com/shankar-sachin/canopy/main/scripts/install.sh | sh   # install script: run it again
$ cargo install --locked --force --git https://github.com/shankar-sachin/canopy canopy-git-tui   # Cargo
